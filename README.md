# Fault-Tolerant Distributed Systems

A dependable-systems project focused on evaluating how faults affect distributed trust algorithms and system resilience.

> **Note:** This public portfolio repository documents my project contribution and engineering approach. The original course-team implementation remains private.

## Overview

Developed a simulation framework for fault injection in distributed satellite-constellation networks. The work examines reliability, fault tolerance, and routing efficiency when individual modules fail or face malicious attacks.

## Highlights

- Engineered a framework to inject and evaluate faults in trust-algorithm modules
- Implemented **Triple Modular Redundancy (TMR)** and software-level redundancy strategies
- Benchmarked system resilience under node failures and adversarial conditions
- Quantified how individual module faults influence routing efficiency and overall reliability
- Produced architectural insights for high-availability distributed systems
